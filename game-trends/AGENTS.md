# Game Trend Skills

This repo is a skill library for making money from simple mobile and web games: live trend scans, social-trend scouting, idea brainstorming, idea evaluation, metric tracking, agent build briefs, and zero-budget launches.

When a conversation touches games as a business (trends, ideas, KPIs, publishing, monetization), read `skills/using-game-trend-skills/SKILL.md` first and follow its five rules. Then use the skill it points to:

- `skills/scanning-game-trends/SKILL.md`
- `skills/scouting-social-trends/SKILL.md`
- `skills/brainstorming-game-ideas/SKILL.md`
- `skills/evaluating-game-ideas/SKILL.md`
- `skills/tracking-game-metrics/SKILL.md`
- `skills/writing-game-agent-briefs/SKILL.md`
- `skills/launching-on-zero-budget/SKILL.md`

## Contributing to this repo

- Each skill is `skills/<name>/SKILL.md` with `name` (same as the folder) and a `description` that starts with "Use when" and describes only when to trigger.
- No benchmark values, fees or revenue shares are hardcoded in skills. Skills tell the agent to look them up live and cite them.
- Run `node scripts/validate.mjs` before committing.
